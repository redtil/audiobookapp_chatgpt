Setting up a library for the first time

The library is kept in a private GitHub repository, and books are prepared on GitHub's machines, for free. One-time setup:

  1. Create a private repository named audiobook-data_chatgpt (tick “Add a README file”).
  2. Create a fine-grained token: Repository access → Only select repositories → audiobook-data_chatgpt and this app's repository. Permissions → Contents and Actions: Read and write. This token is your library key.
  3. In this app's repository: Settings → Secrets and variables → Actions → New repository secret, name LIBRARY_KEY, value: the same key.
  4. Paste the key above. On your other devices, use “Add another device” in the app's settings.
